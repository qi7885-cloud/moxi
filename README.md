# 墨息 · BREATH OF INK

一座会呼吸的数字水墨园林。不是"看内容"的网站，而是一件可以"游"的作品。

**打开方式：直接双击 `index.html` 即可**（单文件、零依赖、离线可用；无需服务器）。

## 四个章节，四种交互装置

| 章 | 装置 | 玩法 |
|----|------|------|
| 壹 · 山 | 实时生成的六层远山 | 移动鼠标即起风，山雾随之流变；点击页面任意处落墨成晕；每一次到访的山都不同 |
| 贰 · 声 | 一泓静水与一尾墨鲤 | 以指抚水，涟漪成音（五声音阶，落点越高音越清）；鲤鱼循声而来，受惊而散 |
| 叁 · 墨 | 会呼吸的毛笔手卷 | 笔锋随速度而变：疾则枯细，缓则丰润，溅墨随缘；可研墨、钤朱印、收卷存 PNG |
| 肆 · 时 | 随真实时刻更衣的园林 | 晨起微赭、日中宣白、暮时带暖、入夜墨青（含星月夜山）；点色签可先窥四时 |

## 细节

- 载入是一场仪式：墨金印章 + 衬线计数 + 「研墨 · 调纸 · 起笔」
- 顶栏是实时**时辰钟**（子丑寅卯……），随时刻自动换墨色
- 差速惯性卷动、朱印光标（悬停变形：「抚水」「落墨」）、颗粒噪点、顶部渐隐如雾
- 按 `I` 键，即刻入夜 / 回昼
- 声音由 WebAudio 当场合成（弦拨 + 回声），无一采样，默认静音
- 尊重 `prefers-reduced-motion`；触屏设备自动隐藏自定义光标

## 技法

纯原生 HTML / CSS / Canvas 2D / WebAudio，无任何框架与外部资源：
分层值噪声（fbm + 折脊）生成山形 · 鼠标速度场驱动风 · multiply 混合模拟宣纸洇墨 ·
Karplus 式双振荡器 + 反馈延迟合成琴音 · CSS 自定义属性驱动四时配色。
